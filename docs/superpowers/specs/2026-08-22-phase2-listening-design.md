# Phase 2 — Listening ("Nghe kể chuyện") design

Refines §2.2A of `docs/2026-08-22-giai-phap-va-design-brief.md`. Phase 1 (Speak Lab) is merged on `main`.

## Goal
A 9-year-old listens to a 60–120 s illustrated story with soft background music, sees the words light up karaoke-style in sync with the narration, can slow it down, tap any word to hear it again, toggle Vietnamese subtitles, then answers 3 picture questions and retells one sentence into the mic.

## Scope (this phase)
- 3 stories (A1 English, 6–7 scenes, 1–2 short sentences per scene): *The Little Fox*, *At the Zoo*, *My Breakfast*.
- Story player with: scene art (large emoji on a gradient; optional PNG if provided later), karaoke text (current word enlarged + coral, past words grey), Play/Pause, speed 🐢 0.75× / 🐇 1×, prev/next scene, scene progress dots, 🎵 background-music toggle, 🇻🇳 subtitle toggle, tap-a-word to replay it.
- Quiz: 3 questions, each "pick 1 of 3 emoji pictures"; Foxy says right/wrong; retry allowed.
- Retell: one target sentence, record with the mic, lenient stars (encouraging), no phoneme hint.
- Progress: story stars in the existing `localStorage` star store (`story:<id>` = quiz stars, `retell:<id>` = retell stars). Home gets a "🎧 Nghe kể chuyện" card; Stories list shows stars per story.

Out of scope: AI illustrations (placeholder art now), streak/mascot animations, parent dashboard.

## Audio & timing
- Narration per scene: `client/public/audio/stories/<storyId>/scene-<n>.mp3`, generated by `scripts/gen-story.mjs` with the Azure Speech **SDK** (not REST) so `WordBoundary` events give `{ offsetMs, durationMs }` per word; the script writes them back into the story JSON (`scenes[n].words[i].start/end`).
- **No-audio fallback** (before the user runs the script): the player drives the karaoke from `estimateTimings(text, wpm=110)` with a silent clock. Everything else works identically, so the feature is testable without Azure.
- Background music: procedural ambient pad via Web Audio (two detuned triangle oscillators + slow LFO + low-pass, gain 0.06), started on the first Play tap (iOS gesture rule), loops forever, toggle in the UI, remembered in `localStorage` (`speakup.music`). No music file needed; if `client/public/audio/music/bg.mp3` exists later it is preferred.
- Playback rate via `HTMLAudioElement.playbackRate` (fallback clock scales the same way). Tap-a-word: seek to `start`, play until `end`, then pause.

## Data shape (`client/src/content/stories/<id>.json`)
```ts
type StoryWord = { w: string; start?: number; end?: number }   // ms, absent until generated
type Scene = { text: string; textVi: string; emoji: string; bg: string /* css gradient */; audio: string; image?: string; words: StoryWord[] }
type QuizQ = { q: string; qVi: string; options: { emoji: string; label: string }[]; answer: 0|1|2 }
type Story = { id: string; title: string; titleVi: string; emoji: string; scenes: Scene[]; quiz: QuizQ[]; retell: { text: string; textVi: string } }
```
`words[]` is always present (split from `text` at authoring time) so tapping works before timings exist.

## Scoring rules
- Quiz stars = correct answers on first try: 3→3★, 2→2★, else 1★ (never 0 — encouraging).
- Retell stars from `PronunciationResult.overall`: ≥60→3★, ≥35→2★, else 1★; message only ("Tuyệt vời! / Hay lắm! / Bé kể tốt lắm, thử lại nhé!"), no hint.
- Both stored with `setStars` (keeps max).

## Architecture
- `client/src/speaking/useSpeakingAttempt.ts` — extracted from `PracticeCard` (recorder + scorer + auto-stop + token refresh + Web Speech branch) so Retell and PracticeCard share one reviewed flow. PracticeCard keeps its UI; its tests stay green.
- `client/src/story/timing.ts` (pure), `client/src/story/music.ts` (Web Audio), `client/src/story/useStoryPlayer.ts` (hook), `client/src/content/stories/index.ts` (`STORIES`, `findStory`).
- Components `SceneArt`, `Karaoke`, `PlayerControls`; screens `StoryList`, `StoryPlayer`, `StoryQuiz`, `StoryRetell`.
- Routes: `/stories`, `/story/:id`, `/story/:id/quiz`, `/story/:id/retell`.

## Constraints (inherit Phase 1 Global Constraints)
Tap targets ≥ 64 px; karaoke text ≥ 32 px; Vietnamese UI copy; en-US; Azure key only in `server/.env`; secret-leak hooks stay in force; all tests/lint/typecheck/build green.
